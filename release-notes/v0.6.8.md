## What's new in Asset Manager 0.6.8

### Profiles
Keep separate libraries for separate work, such as a ZBrush profile and a Substance Painter one, and switch between them so files from other programs stay out of the way.

- **Each profile has its own** library folders, file types, sidebar categories and collections.
- **Shared by every profile:** tags, favorites and ratings (they belong to the files), and the theme, apps, viewer and Artbook settings.
- **Switch** with the profile button at the top left, or **Ctrl+Shift+P**. The profile's last scan shows straight away while it rescans in the background, and the window title shows which profile is in use.
- **New Profile...** starts as a copy of the current profile, or **Empty**: no folders and no categories, so the sidebar has just All Assets and Favorites.
- **Settings > Profiles** renames, duplicates and deletes profiles. Changes apply when you click Save. The profile in use can't be deleted, and deleting one never touches your files, tags or ratings.
- **Desktop Shortcut** puts an icon on the desktop that opens the app in that profile. It keeps working if you rename the profile. `AssetManager.exe --profile <name>` works too.
- **Collections:** right-click one to **Show in Every Profile** or **Move to Profile**.
- **Your current setup** becomes the **Default** profile, with your folders, categories and collections unchanged. The app starts in the last profile you used.

Switching profile doesn't make the app read your files' details again: what's known about files in other profiles' folders is kept.

### Categories by tag
A sidebar category can now show files by tag as well as by file type. For example, a "Main Project" category can show every FBX file plus anything tagged "Main", whether it's an image, a video or a tool file.

- In **Settings > Categories**, a category has **File Types** and **Tags**. Choose whether a file needs **any of these tags** or **all of them**.
- Right-click a tag in **Settings > Tags** and choose **Add as Sidebar Category**.
- Renaming a tag renames it in every category, in every profile. Deleting a tag removes it from categories, and the categories stay.
- Counts and the grid update as you tag files.

### Also changed
- Sidebar categories and Collections start collapsed, so the sidebar doesn't fill up when the app starts, when you switch profile, or when you change categories. Ones you open stay open until you switch profile.
- The library database is upgraded so collections can belong to a profile. A backup is made before the upgrade.
