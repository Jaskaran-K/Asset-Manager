## What's new in Asset Manager 0.6.15

### Browser extension
Right-click a picture on a web page in **Chrome** or **Opera GX** > **Asset Manager** > **Save to Library** or **Add to Artbook Page**. The app doesn't need to be open. A small note in the page's corner says where the picture went.

**Save to Library**
- **Where it goes:** the profile's web folder, in a folder for each site (`artstation.com`, `pinterest.com`). Unless you pick another folder in **Settings > Browser**, that's **Web Images** in the profile's first library folder. Each profile has its own.
- **Its name:** the picture's own name, or the page's title when the name is just a code.
- **The biggest version is taken:** the picture a link points to, the largest of the sizes the page offers, ArtStation's 4K copy, or Pinterest's original.
- **No copies:** a picture that's already there isn't saved again.
- **File types:** a type the profile doesn't show, such as WebP or AVIF, is saved as PNG or JPG.
- **Open Source Page:** right-click a saved picture in the library to open the page it came from.
- **Tags:** to tag pictures as they arrive, give the folder a folder rule.

**Add to Artbook Page**
- The picture goes on the page that's open, or the one last open.
- If the app is closed, the picture goes on the page when the app next opens.

**Pictures behind a login**
When a site refuses the app, the browser downloads the picture with your login, and the app moves it into place.

**Setting it up**
1. Go to **Settings > Browser** and click **Set Up**.
2. In each browser, open its extensions page (the buttons in Settings open them).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and pick the folder shown (**Copy Folder Path** copies it).

Set Up adds one registry entry for your Windows user, which both browsers read. It needs no admin rights, and **Remove** takes it away again.

**Safety**
- No network port is opened. The browser starts the app's helper for each picture, and only for this extension.
- The extension can't read the sites you visit. It only reaches the tab you right-click, at the moment you do, plus downloads for the login case.

### Faster helpers
The app's helper programs (the model reader, the AI tools and the browser helper) start faster.
