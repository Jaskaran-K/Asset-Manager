## What's new in Asset Manager 0.7.51

### Fixes
- **KeyDial starts again.** In 0.7.50, KeyDial closed with an error as soon as it started, whether you used KeyDial.exe from the release page or the copy the installer adds.
- **KeyDial's start-up check:** the check each release runs now goes through KeyDial's whole start-up, so a problem like this stops the release before it's published.

KeyDial is the bonus app for the Huion KD100 from 0.7.50: see that release's notes for what it does.
