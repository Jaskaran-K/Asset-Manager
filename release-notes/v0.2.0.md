## What's new in Asset Manager 0.2.0

### 🎬 Video playback
- Videos (`.mp4`, `.mov`, `.mkv`, `.avi`, `.webm`, `.m4v`) now play inside the viewer, with play/pause, a seek bar, current/total time, and volume.
- **Seek bar:** click anywhere to jump there, or drag to scrub. Hovering or dragging shows a small preview frame with its timestamp.
- **Jump buttons:** back and forward buttons use a jump time you choose (1, 5, 10, 15 or 30 seconds). The Left and Right arrow keys use it too, and your choice is remembered.
- **Fullscreen video:** click the button, press **F**, or double-click the video. The controls and cursor hide while it plays and come back when you move the mouse. **Esc** exits.
- **Files that won't play** (some pro codecs such as ProRes or DNxHR) or that stutter show a clear message with a **Generate 720p Preview** option. ffmpeg makes the preview in the background and caches it, so it only happens once per file. A **720p Proxy** button is also always available for heavy footage.
- **Video thumbnails:** grid thumbnails show a frame from the video with a play badge.
- **New Settings > Video page:** set the ffmpeg location, choose the playback backend (FFmpeg or Windows Media Foundation), and clear the preview cache.
- Thumbnails and previews need [ffmpeg](https://ffmpeg.org/) (for example `winget install ffmpeg`). Playback works without it.

### 🏷️ Tags
- **File type tags** (PNG, FBX, JPEG, ...) are added automatically to every file, including your existing library on its first scan.
- **Custom tags** with colors: create, rename, recolor and delete them in **Settings > Tags**, with file counts. Deleting asks for confirmation and tells you how many files are affected.
- **Tag one or many files at once:** select them and press **Ctrl+T**, click **🏷 Tag**, or right-click and choose **Tag...**. Checkboxes show whether all, some or none of the selected files have each tag, and you can create a new tag right in the dialog.
- **Search by tag:** type `tag:name` (or `tag:"two words"`) in the search bar, or pick from the suggestions. Tags become colored chips. Several tags must all match, and you can combine them with file name text. **Backspace** removes the last chip; **Esc** or **✕** clears everything.
- **See tags everywhere:** the viewer's metadata panel shows a file's tags (with an **Edit Tags...** button), and grid tooltips list them.

### 🖥️ Viewer
- The viewer window now has a **maximize** button and a **Full Screen** button (or press **F11**). **Esc** leaves full screen.
- **Image viewer checkerboard** (hover hint: "Check Transparency"):
  - It's now a visible light grey/white pattern.
  - It turns on automatically only for images that actually have transparency.
  - It no longer slows down zooming: before, a deep zoom could take seconds per frame.
- The metadata panel now shows whether an image has **Transparency**.

### ⌨️ Shortcuts
- New **Settings > Shortcuts** page lists every keyboard shortcut and mouse control, grouped by where it works, with a filter box.

### ✨ Other improvements
- The app has its own icon on the window, the taskbar and `AssetManager.exe`.
- The viewer frees its memory when you close it. Previously every opened viewer stayed in memory until the app closed.

### ⚠️ Good to know
- Tags are linked to file paths, so moving or renaming a file outside the app loses its tags.
- Changes on **Settings > Tags** are saved immediately; **Cancel** doesn't undo them.
- Tag searches match files that have *all* the selected tags. OR search isn't available yet.
